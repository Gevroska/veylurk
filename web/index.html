      How to read these events
      NAMES
      The account appeared in a received chat membership response. A response can be partial or delayed.
      JOIN
      A chat membership JOIN message was received. It is not a verified arrival time.
      PART
      A chat membership PART message was received. It is not a verified departure time.
      NAMES end
      A response terminator was received. It proves neither a complete list nor an empty room.

          Stop collection and close Veylurk now?

          Collection gaps

          Disconnects, restarts, pauses, and configuration changes can interrupt collection. Open a channel’s history to inspect its recorded sessions and end reasons. An open session does not guarantee complete membership delivery.

          Retention

          Stored history is retained indefinitely in the local SQLite database. Pausing or removing channel tracking does not delete that history.
